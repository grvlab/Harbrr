01Getting Started

Harbrr is a Windows desktop app that lets you monitor and manage all network connections on your system. Think of it as a visual, interactive layer on top of netstat.

Monitor Connections

See every TCP/UDP connection with process names, ports, addresses, and states.

Kill Processes

Terminate processes hogging ports with a single click, individually or in bulk.

Check Port Availability

Instantly check if a specific port is free or see what's using it.

Export Data

Download your filtered connections as a CSV file for further analysis.

App Layout

The app has three main areas:

  • Title Bar — shows the app name and window controls (minimize, maximize, close, and this help button).
  • Sidebar — navigation between Dashboard and Port Checker, theme toggle, and system info at the bottom.
  • Main Area — the active page content (Dashboard or Port Checker).

02Dashboard

The Dashboard is the main screen. It shows all active network connections on your system in a powerful, filterable table.

Stats Cards

At the top you'll see five summary cards:

CardShows
TotalTotal number of connections
ListeningConnections in LISTENING state (server ports)
EstablishedActive connections to remote hosts
Open PortsUnique listening ports
ProcessesUnique process IDs with connections

Search

The search bar filters across all fields at once — type a port number, process name, IP address, or PID and the table updates instantly.

Filters

Use the filter buttons to narrow by:

  • Protocol — All, TCP, or UDP
  • State — All, LISTENING, ESTABLISHED, TIME_WAIT, CLOSE_WAIT

Sorting

Click any column header to sort by that column. Click again to reverse the sort direction. The current sort column shows an arrow indicator.

Column Chooser

Click the funnel icon (Columns) in the toolbar to show or hide columns. Your preferences are saved automatically and persist between sessions.

Tip: Hide columns you don't need to reduce clutter. For example, hide "Remote Address" and "Remote Port" if you only care about listening ports.

Row Selection

Check the box on any row to select it. Select multiple rows and use the Kill Selected button in the floating action bar to terminate processes in bulk.

Context Menu

Right-click any row to access quick actions: View Details, Copy Address, Copy PID, and Kill Process.

03Connection Details

Click the eye icon on any row (or double-click the row) to open the detail panel. It shows the full breakdown of a connection:

  • Process — PID and process name
  • Protocol & State
  • Local Endpoint — address and port
  • Remote Endpoint — address and port

From the detail panel you can copy the full address or kill the process directly.

04Port Checker

Navigate to Port Checker in the sidebar. Enter any port number (1–65535) and press Enter or click Check.

The result will tell you:

  • Available — the port is free and ready to use.
  • In Use — shows which processes are using it, with protocol, state, and a kill button for each.

Quick-check buttons for common ports (80, 443, 3000, 3001, 5173, 8080, 8443) are shown below the input for fast access.

05Managing Processes

Kill a Single Process

You can kill a process from three places:

  1. The kill button (X icon) on any table row
  2. The right-click context menu
  3. The connection detail panel

Bulk Kill

Select multiple rows using checkboxes (or click the header checkbox to select all), then click the Kill Selected button that appears in the floating action bar.

Important: A confirmation dialog always appears before killing a process. System processes (PID 0 and 4) cannot be terminated. Be careful when killing processes — this action is irreversible.

06Auto-Refresh

Click the activity icon (pulse line) in the toolbar to toggle auto-refresh. When enabled, the connections table refreshes every 5 seconds.

A green indicator appears in the toolbar showing auto-refresh is active. Click the button again to disable it.

Tip: Use auto-refresh when monitoring for new connections or waiting for a port to become available.

07CSV Export

Click the download icon in the toolbar to export the currently filtered data as a CSV file.

  • Only the currently visible rows (after search and filters) are exported.
  • Only visible columns (as set in the column chooser) are included.
  • The file is named with a timestamp, e.g. ports-2026-02-10T14-30-00.csv

08Themes

Harbrr supports two themes:

  • Dark Mode (default) — easy on the eyes with a deep navy palette.
  • Light Mode — clean white and blue for well-lit environments.

Toggle the theme using the sun/moon button in the sidebar under Preferences. Your choice is remembered across sessions.

09Tips & Tricks

  • Quick search by process — type a process name like node.exe or chrome to instantly filter.
  • Find listening ports — set the state filter to LISTENING to see only server ports.
  • Identify port conflicts — use Port Checker before starting a dev server to confirm the port is free.
  • Right-click for speed — the context menu on table rows is the fastest way to copy data or kill a process.
  • Column memory — your visible columns are saved in the browser, so they persist across sessions.
  • Refresh manually — click the refresh button (circular arrow) to reload connections on demand.
  • Double-click for details — double-click any row to instantly open the detail panel.
  • Bulk operations — select multiple rows then use Kill Selected to clean up many connections at once.
